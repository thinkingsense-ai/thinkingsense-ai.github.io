Admin console cheat sheet

Every page of the admin console (/admin) on one page: where it is, what it is for, and the one thing to know. Press ⌘K (Ctrl K) anywhere in the console to jump to any page, data source, trusted question, term, group, skill or dashboard by name.

Which release? This is the console layout on main, shipping in the first release after 0.10.22. In 0.10.22 and earlier the same pages are grouped as Data Sources, Business Catalog, Answer Quality, Automation, Operations and Settings: see the Admin & Ask guide.

On every page

PartWhat it doesKnow this
🏠 Home
/admin		What needs you now (suggested fixes, failed questions) and four status cards: trusted questions, tests passing, questions in the last 7 days, dashboards. Then data sources and models.Home and Conversations count the same way: questions asked by people in the last 7 days, test runs and alerts left out, a deep analysis counted once.
Workspace switcherThe breadcrumb's first step (Org / Default) picks the workspace every page edits.Each workspace has its own context, tests and versions.
Version barUnder the top bar: the draft (Draft · N changes or No unpublished changes), the live version and its tests (v4 live · 12/12 tests), Save version and Publish.Edits land in the draft; business users keep getting the live version until you publish. Save version runs the tests first. Click the live pill for the full history and roll-back. Read-only admins see the state without the buttons.
🔔 BellEverything waiting on an admin: failed questions, thumbs-down votes, open help requests, data-model decisions, MCP tools awaiting a decision, and data sources with a failed step.Click it for the list; each item opens its page.
More (in each group)Less-used pages of that group, with a badge summing theirs.Everything is also in ⌘K.
⚙️ Org settingsThe foot of the sidebar: settings shared by every workspace.Badge sums the settings pages' badges. See Org settings.
💬 Open AskOpens the business users' Ask app.To see what a particular person would get, use Playground instead.

Context what your data means

PageWhat it is forKnow this
🗺️ Data model
/admin/ontology		Which tables and columns the agent may use, what they mean, how tables relate, and which inferred relationships you approved. Tabs: Tables, Entities & terms, Relationships, Review.Test access as shows the model as a given user sees it. Undescribed tables? Let Builder draft the descriptions.
📖 Business terms
/admin/context-builder		The glossary every answer uses: what “revenue at risk” means in your data, with its formula and definition.A term is applied only when a question uses it; Playground's What it used shows which terms an answer used.
📐 Metrics
/admin/metrics		Named, governed measures; dbt import; an ad-hoc metric query runner.Metrics can be watched by Alerts.
⭐ Trusted questions
/admin/question-bank		Approved question-to-SQL pairs. A matching question is answered directly from its approved SQL.Every trusted question is also a test (see Tests). Answers that matched one show “Matches a trusted question” in Ask.
📜 Instructions
/admin/instructions		Plain-language rules every answer in the workspace follows, such as “Fiscal year starts in April”.Apply to every answer in the workspace.
📚 Knowledge More
/admin/knowledge		Documents answers can cite (policies, runbooks, contracts, notes), who may read each one, and the facts and preferences the system remembers.Cited documents show as a chip under the answer in Ask.
📏 Rules More
/admin/domain-rules		Mechanically verified facts about your data: NOT NULL, UNIQUE, allowed values, ranges.Verified against the data, not typed in by hand.
🗂️ Versions
/admin/versions		The draft, every saved version with its test results, and which one is live.Reached from the version bar's live pill (not in the sidebar). Publish or roll back from here.

Develop make answers right before people rely on them

PageWhat it is forKnow this
🧪 Tests
/admin/tests		Trusted questions asked through Ask the way a business user asks them, and checked against their known right answer, row by row.Shows the score of the latest run and the run history; open a test to see expected rows next to the answer.
🛠️ Improvements
/admin/improvements		Wrong, corrected and failed answers turned into suggested fixes.Accept a fix to apply it to the draft, add a test, and see the answer before and after.
🛝 Playground
/admin/explore		Ask a question and see exactly how it is answered: business meaning, data used, SQL and execution plan.Asking as a user applies their access rules; What it used lists the tables, terms, filters and model.
🧱 Builder
/admin/builder		An agent that reads your tables and proposes business terms, metrics, descriptions, join keys and trusted questions.Nothing is saved until you accept each proposal.

Monitor what people asked and how it went

PageWhat it is forKnow this
💬 Conversations
/admin/query-intelligence		Every question asked. Sessions shows one row per conversation; Answers one row per question. Each row: outcome, feedback (with the “Not right” reason), where it was asked, the version, time and cost.A deep analysis is one session (“🔬 Deep analysis · N steps”); open it for its steps. Where defaults to Asked by people: choose Anywhere, with tests and alerts to include test runs. Columns and CSV export in the toolbar.
📝 Review queue
/admin/review		Answers people marked “Not right” and requests for help, each with a drafted correction.The reason the person picked (wrong data, wrong numbers, misread question, wrong period, presentation) shows on the case.
📈 Usage
/admin/usage		Who asks what; answer and no-answer rates; thumbs; latency; model cost by tier, workspace and entry point.Counts each deep-analysis step as its own question.
🚨 Failing questions More
/admin/needs-attention		Questions that failed, each classified as fixable here or a backend problem.Its badge counts all time; Home's failed count is the last 7 days.
🔔 Alerts More
/admin/alerts		Trusted questions, metrics and questions checked on a schedule, as a chosen person, telling people when a condition is met.Business users can also set one from an answer's ⋯ → Alert me when….

Ship get answers to people and systems

PageWhat it is forKnow this
📊 Dashboards
/admin/dashboards		Saved collections of approved questions, re-run live each time they open.Users add answers with Save on the answer card.
🧩 Skills
/admin/skills		Named shortcuts to a saved question that business users type as /name in Ask.Indexed by ⌘K as /name.
🔌 Embed, API & MCP
/admin/developers		The MCP endpoints and embedding SDK this deployment exposes, with copy-paste client config.See Securing /mcp/agent.
📮 Destinations More
/admin/destinations		Where answers are sent (Slack, webhooks and APIs, email), the hosts they may reach, and a log of every send.Alerts and Send to… deliver through these.
🚀 Deploy More
/admin/deploy		Publish a trusted question as an API endpoint or embeddable card, computed as the person you choose.The endpoint runs with that person's access rules.
📡 Change watch More
/admin/insights		Approved questions watched on a schedule, flagging material changes and broken queries.Shown when insights are enabled.
🔀 Workflows More
/admin/workflows		AI decision workflows started from Ask: definitions, recent runs and the tamper-evident decision record (read-only).Shown when the workflow engine is on (commercial licence). Runs are started and approved in Ask.

Org settings shared by every workspace · /admin/settings

PageWhat it is forKnow this
Data
🗄️ Data sources
/admin/sources		Register and manage the databases, APIs and files questions are answered from.Connection health is also on Infrastructure.
📤 Uploads
/admin/csv-uploads		Upload a CSV and query it like any other source.Business users can also drop a file into Ask if allowed to.
🧾 Documents
/admin/pdf-extract		Pull structured fields out of a PDF with the configured model.
☁️ SaaS apps
/admin/oauth-connectors		Connect SaaS sources with one click instead of pasting a token.Shown when OAuth connectors are enabled.
🔗 MCP servers
/admin/mcp-servers		External MCP tools a question may call, discovered from each server and approved by you.Configure with OMNIGATE_MCP_SERVERS; only approved or read-only tools run.
Models
🧠 Models
/admin/llm-settings		Which models answer questions, their live status and today's traffic split.Local first with escalation to a stronger model when unsure is one of the modes.
People & access
🔑 Users & access
/admin/users		Admin and business-user accounts and their roles; whether a user may see SQL, see source names, upload files.A user who may not see sources gets “Sources hidden” in Ask.
👥 Groups
/admin/groups		Which data sources and members each group can see and query.With single sign-on, workspaces can follow your provider's groups; see Workspaces from provider groups.
🛡️ Security
/admin/security		What is switched on, column classification (tags), and review of access-policy changes.See column tags and policy history.
System
⚡ Rollups
/admin/rollups		Pre-aggregated tables that speed up common queries.
🏗️ Infrastructure
/admin/infrastructure		Version, uptime, licence, certificate, source connectivity, query engine and model health.First stop when something is slow or down. See Infrastructure.
🔎 Audit log
/admin/audit		Every query and admin action taken on this deployment.
